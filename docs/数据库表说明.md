# NetWatch 数据库表说明

> 生产：PostgreSQL 10.5（`/var/lib/pgsql/data`，仅本机 5432，hba 密码认证）+ VictoriaMetrics v1.102.1（`:8428` 仅本机，90 天保留）
> 本文核对自 `internal/server/store.go` / `tsdb.go` 及生产实测（全库 8.4MB）。巡检/备份/SQL 配方等运维操作见 `AGENTS.md` §8/§14。

---

## 1. 双库分工

| 存储 | 存什么 | 特点 |
|---|---|---|
| **PostgreSQL**（库 `netwatch`，10 张表） | 业务事实：楼层/线路/探针/告警/静默/报表/用户/审计/设置/版本发布 | 全部配置的**唯一权威来源**，重启不丢 |
| **VictoriaMetrics** | 时序样本：全部探测曲线 | 只追加，**90 天自动过期**；丢失只影响历史曲线 |

库外状态：Web 会话在 server **内存**（重启需重登录）；SSH 凭据密文在 PG 但**主密钥在 `data/ssh-master.key`**；探针本地 `identity.json`（身份）+ `cache.jsonl`（断网缓存 48MB 上限、500 条/批补传）。

## 2. 表关系

```
floors ──< lines ──< probes
             │  ＼
             │   └──< silences      （删线路 → 级联删静默）
             └─ 弱关联：alerts.line_id / alerts.probe_id（普通列，无外键）
独立表：settings / users / audit / reports / agent_releases
```

外键行为：删楼层 → 线路 `floor_id` 置 NULL；删线路 → 探针解绑（SET NULL）+ 静默级联删除；删探针（后台）→ 其盲区告警与幽灵状态自动收口。

## 3. 各表结构

### 3.1 floors（楼层/子网）

| 列 | 类型 | 说明 |
|---|---|---|
| id | SERIAL PK | |
| name | TEXT | 楼层名（如"3楼"） |
| cidr | TEXT | 子网 CIDR |
| created_at | TIMESTAMPTZ | |

### 3.2 lines（宽带线路）

| 列 | 类型 | 说明 |
|---|---|---|
| id | SERIAL PK | 被 probes/silences 引用 |
| name | TEXT | 线路名（唯一性由后台校验） |
| isp | TEXT | 运营商（默认'联通'；可由探针自动探测回填） |
| public_ip | TEXT | 出口公网 IP（**由探针每 5 分钟探测对账纠偏**，手工改写约 15s 被纠正） |
| contract_down_mbps / contract_up_mbps | INT | 契约带宽 = 带宽不达标告警阈值；0=不判 |
| floor_id | INT → floors | ON DELETE SET NULL |

### 3.3 probes（探针）

| 列 | 类型 | 说明 |
|---|---|---|
| id | **TEXT** PK | 探针 ID（注册生成，探针本地持久化复用） |
| secret | TEXT | 上报凭证（每次上报鉴权） |
| hostname / os / arch / version / source_ip / gateway | TEXT | 注册与心跳自报（含资产信息） |
| name | TEXT | 后台设置的显示名 |
| line_id | INT → lines | 绑定线路 |
| grp | TEXT | `internal`（内网组）/ `external`（外网组） |
| ssh_host / ssh_port / ssh_user / ssh_pass_enc | | 零接触运维凭据；密码仅存 **AES-256-GCM 密文** |
| pending_version | TEXT | 待升级版本号（完成自动清空） |
| enrolled_at / last_seen | TIMESTAMPTZ | 注册时间 / 最后心跳（盲区判定：>60s） |

### 3.4 alerts（告警，唯一带索引的大表）

| 列 | 类型 | 说明 |
|---|---|---|
| id | BIGSERIAL PK | |
| fingerprint | TEXT | 同一问题唯一指纹（状态翻转依据） |
| severity / kind | TEXT | P0/P1/P2；kind=blind/line_down/floor_down/degraded/speed_low/probe_conflict/site_down/site_conflict/cert_expiring/monitor_down/probe_resource/industry_down |
| title / body | TEXT | 标题与详情（邮件正文同源） |
| probe_id / line_id | TEXT / INT | 弱关联（无外键） |
| starts_at / ends_at | TIMESTAMPTZ | 触发/恢复时间 |
| status | TEXT | `firing` / `resolved` |

恢复 = 更新原行（status→resolved、补 ends_at），不新增行。索引 `idx_alerts_status(status, starts_at DESC)`。**无自动清理**。

### 3.5 settings（全部可配置项，JSONB）

| key | 内容 | 后台入口 |
|---|---|---|
| agent_config | 内网组探测下发（间隔/超时/目标 + **version 乐观锁**，手改不递增则不下发） | 设置 → 探测配置 |
| agent_config_external | 外网组官网探测配置 | 设置 → 探测配置 |
| internal_monitors | 内→内内置监控 | 设置 → 探测配置 |
| industry_monitors | 行业网监测（仅 ICMP ping） | 设置 → 探测配置 |
| smtp | 邮件服务器（GET 时密码掩码 `__SET__`，PUT 空/占位符=保留原值） | 设置 → 通知渠道 |
| notify_channels | 钉钉/企微 webhook | 设置 → 通知渠道 |
| alert_settings | 告警阈值 + 收件组 | 设置 → 告警策略 |
| speed_settings | 测速引擎/间隔/下载源 | 设置 → 采集与测速 |
| snmp_settings | SNMP 采集 + 接口映射 | 设置 → 采集与测速 |
| report_settings | 日报/周报计划 | 设置 → 报表推送 |
| agent.enroll_token | 注册令牌（**存在即覆盖** unit 环境变量） | 设置 → 探测配置 |

首次启动自动写入 9 个默认键（`ON CONFLICT DO NOTHING`）；API PUT 有白名单（仅以上 10 键）。

### 3.6 其余表

| 表 | 用途 | 要点 |
|---|---|---|
| users | 后台账号 | username UNIQUE；bcrypt 密码；role=`admin`/`viewer`（viewer 写操作 403）；**无会话表** |
| reports | 日报/周报 | kind=day/week；**data JSONB** 存整份统计；CSV 导出由其生成 |
| silences | 静默窗口 | line_id NULL=全部线路；到期自然失效 |
| audit | 操作审计 | 每个写操作一行；后台显示最近 100 条；无自动清理 |
| agent_releases | 探针版本发布 | 元数据（version/sha256/size…）；文件本体在 `data/agent-releases/<版本>/` |

## 4. VictoriaMetrics 指标体系

| 指标 | 含义 | 标签 |
|---|---|---|
| nw_ping_rtt_ms / nw_ping_ok / nw_ping_loss_pct | ICMP 时延/成败/丢包 | probe, line, class=`gw`\|`public`, target |
| nw_tcp_rtt_ms / nw_tcp_ok | TCP 连通 | probe, line, target |
| nw_dns_rtt_ms / nw_dns_ok | DNS 解析 | probe, line, target |
| nw_http_ttfb_ms / nw_http_ok / nw_http_code / nw_http_cert_days | HTTP 首字节/成败/状态码/证书剩余天数 | probe, line, target |
| nw_speed_down_mbps / nw_speed_up_mbps | 测速上下行 | probe, line, target |
| nw_snmp_in_bps / nw_snmp_out_bps | 防火墙 WAN 口真实流量 | line（中心采集） |
| nw_monitor_ok / nw_monitor_rtt_ms | 内→内内置监控 | monitor, type（无 probe 标签） |

- `class=gw|public` 区分网关/公网探测，是楼层中断/线路中断分类判定与探测历史分类的基础；
- 保留 90 天；量级参考：12 线路满配 30 天 <100MB；
- **即时查询有 ~30s latencyOffset**（刚写入查不到属正常；导出/区间查询不受影响）；
- 原生 API 仅本机可访问，后台"线路详情/探测历史"已封装常用查询。

## 5. 数据增长与保留

| 数据 | 自动清理 | 建议 |
|---|---|---|
| VM 时序 | ✅ 90 天 | 无需管理 |
| alerts / audit / reports / silences / agent_releases | ❌ | MB 级年增长；需要时按 AGENTS.md §14 配方清理（`DELETE FROM alerts` 等） |

表结构变更由**中心端启动时自动迁移**（`CREATE TABLE IF NOT EXISTS` + `ALTER ... ADD COLUMN IF NOT EXISTS`），升级即完成，无需手工 SQL。
