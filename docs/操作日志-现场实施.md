## 三、待执行：逐台开通操作手册（probe-5 ~ probe-11 及专线补位）

### 每台通用步骤（约 1 分钟/台）

1. **准备**：全新干净服务器（麒麟 V10），设置 IP=10.8.14.<尾段>（见对照表），root 可达
2. **开通**：登录 `http://10.8.14.200/#/probes/manage` → **＋ 新建探针** → 填写：
   - 服务器 IP：`10.8.14.<尾段>`；SSH 端口 22；用户 root；密码（输入一次）
   - **探针名称**：`probe-<序号>`（对照表见下）
   - **预期线路**：选对应线路（**务必选**——出口会自动登记为该线路身份并绑定，含暂未分配楼层的线路6/8）
3. **核对弹窗进度**（七步，约 20 秒）：SSH 连接 → 免密配置 → 主机名 probe-<尾段> → 上传+sha256 校验 → systemd → 注册 → 出口 IP 探测 → 登记到预期线路/绑定
4. **⚠ 处理**：若出现"出口 IP 与预期线路不符"= 该探针的策略路由指错线——改防火墙映射后点 🔄 立即刷新，系统自动改绑
5. **开通后 10 秒核对**（三处）：
   - 探针管理列表：该探针 online、绑定线路正确
   - 📈 线路状态页：对应线路卡片出现探针名、出口 IP 已登记
   - 楼层归属：卡片楼层与对照表一致
